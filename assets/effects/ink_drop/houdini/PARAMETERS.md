# Ink Drop Parameters

All artist controls are on `/obj/INK_DROP_EFFECT`.

## Animation

| Control | Purpose |
|---|---|
| Start Frame | First appearance of the top-center drop. |
| Form End | End of the small-drop phase; default frame 6. |
| Stretch End | End of downward stretching; default frame 12. |
| Cloud End | End of cloud/tendril expansion; default frame 24. |
| End Frame | Editorial end marker; default frame 48. |
| Motion Speed | Multiplies continuous noise/drift time. |
| Impact X / Y | Top-center growth anchor in SOP space. |

## Cloud Shape

Cloud Width/Height set the mature silhouette. Top Neck Width keeps the upper attachment narrow, while Top Neck Length controls how gradually it opens into the wider bloom below. Edge Noise breaks the rim; Noise Scale changes feature size; Turbulence moves interior points; Curl Amount adds flowing lateral curls; Tendril Amount lengthens downward lobes. Radial and Angular Segments control mesh density. Rebuild after changing segment counts if the viewport does not immediately recook.

## Layer Depth

Visible Layers hides higher layer IDs through opacity. Depth Spacing prevents coplanar flicker. Depth Drift adds independent motion in Z. Parallax converts shallow Z differences to a slight X shift for a more volumetric camera view.

## Persian Texture

Persian Pattern Texture accepts an RGBA PNG. Use Texture switches between the PNG and Ink Tint. Texture Repetition tiles it; Pattern Rotation rotates UVs; Texture Growth changes pattern scale independently of cloud growth; UV Distortion embeds it into deformation; UV Animation Speed drifts it gently.

## Dissolve

| Control | Purpose |
|---|---|
| Dissolve Start Frame | First breakup frame. |
| Dissolve Duration | Frames to reach final breakup. |
| Dissolve Noise Scale | Size of breaking regions; higher means smaller islands. |
| Dissolve Softness | Width of transparent region boundaries. |
| Dissolve Turbulence | Speed/strength of animated dissolve noise. |
| Final Opacity | Residual opacity after the dissolve. |
| Fragment Drift | Outward motion of disappearing regions. |

Each layer adds a small dissolve delay automatically.

## Bubbles

The current build uses one closed 3D hero bubble rather than multiple planes or a particle cloud. Its master panel is `/stage/ink_drop_hero_bubble_controls`; all values can be keyframed directly in Solaris.

**Hero Bubble Animation** exposes Growth Start/End, Final Radius, Growth Overshoot, Position X/Y/Z, Rise Speed, Left/Right Skid, Skid Frequency, Surface Wobble, Wobble Scale/Speed, Top Pin Falloff, Top Widen Start/End, Final Top Width, Top Widen Falloff and Scale X/Y/Z. The hero is generated by revolving a hand-shaped half profile around Y. Its top center remains exactly fixed at Position X/Y/Z while translation and wobble fade into the body according to Top Pin Falloff. Over the widening interval, the pointed apex opens radially into a broader rounded top without moving that pinned center. Top Widen Falloff controls how far down the neck this reshaping reaches.

**Surrounding Bubbles** controls Count, Final Radius, Radius Variation, Outside Surface Gap, Birth Spread, Rise Speed, Upward Acceleration, Wobble, Wobble Frequency, Depth Offset, Split Frame/Separation, Turbulence and Seed. Satellite centers are placed beyond the main bubble's current radius plus their own radius and the requested gap. Their randomized depth offset is static, so left/right wobble does not turn into orbiting motion around the hero. Bubble zero splits into two children; every third bubble receives a subtle size pulse. **Air Bubble Material** exposes Reflection, Reflection Roughness, Transmission, Refraction IOR/Roughness, Clear Coat, Coat Roughness and Thin Walled Shell. Every control includes hover/F1 help in Houdini.

## Materials

Ink Tint is used when texture is disabled and also seeds procedural variation. Base Opacity multiplies edge and dissolve masks. Glass Geometry Thickness gives every layer a small closed depth so Karma can calculate actual refraction.

The render-facing controls are exposed directly on `/stage/ink_drop_materials` under **Ink Glass Controls**: Diffuse Weight, Reflection, Reflection Roughness, Transparency/Transmission, Refraction IOR, Refraction Roughness, Transmission Depth, Spectral Dispersion, Clear Coat, Coat Roughness, Pattern Emission, and Thin Walled. These parameters are connected live to `/mat/ink_drop_mtl`. Leave Thin Walled off for physical refraction through the extruded layer thickness; enable it for faster card-style transparency.

## Water Integration

Sync With `/obj/WATER_RIPPLE` is optional and non-destructive. Build Optional Solaris Setup controls creation of the `ink_drop_*` Stage chain when running the builder.
